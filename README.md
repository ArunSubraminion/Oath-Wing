# Oath Wing

Company website for Oath Wing. Pangea Craft is the company's ground-effect maritime product.

Adapted from the updated Pangea repository's index.html and assets. The updated one-page design, product imagery, interactions, and founders@pangeacraft.com product contact address are retained.

## Hosting

For GitHub Pages, commit and push this repository, then select the published branch and /(root) under Settings > Pages. Set the confirmed Oath Wing domain there after deploying. The source's pangeacraft.com CNAME is deliberately not copied because it belongs to the Pangea site.

For GoDaddy web hosting, upload index.html and the assets directory into the domain's document root, commonly public_html. No build is required. A GoDaddy domain can also point to GitHub Pages while Zoho Mail handles email through separate DNS records.

These files are prepared locally; publishing and DNS configuration remain outstanding.
